# MotoBot Colombia v2

App Streamlit con cinco experiencias: investigar, comparar con podio, recomendar, asesorar y calcular costos.

## Instalación
1. `python -m venv .venv`
2. Activa el entorno.
3. `pip install -r requirements.txt`
4. Define `GROQ_API_KEY`.
5. Opcional: guarda `motobot_hero.png` en `assets/`.
6. Ejecuta `streamlit run app.py`.

## Alcance de datos
La IA no sustituye fuentes oficiales. Los precios, inventario y especificaciones deben verificarse con fabricante o distribuidor. El simulador usa las bandas de SOAT 2026 cargadas como referencia y remite a los portales oficiales para verificación.
